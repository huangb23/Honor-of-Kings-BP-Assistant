# backend — BP 胜率预测与选人推荐器

给定"我方部分/满阵容 vs 敌方部分/满阵容 + 已 ban 英雄"，预测胜率，并推荐：
1. **单英雄选人**：按分路给出各位置的 Top8 推荐英雄及对应胜率
2. **双英雄选人**：给出最优的 2 英雄组合及对应胜率

## 快速使用

```bash
cd backend
python3 -u main.py \
    --my 百里守约,墨子,元流之子(坦克) \
    --opp 少司缘,元歌,西施,孙尚香,云缨 \
    --ban 瑶
```

参数：
| 参数 | 说明 |
|------|------|
| `--my` | 我方已选英雄，逗号分隔（可空/部分）|
| `--opp` | 敌方已选英雄，逗号分隔（可空/部分）|
| `--ban` | 已 ban 英雄，逗号分隔（可选）|
| `--role` | 只推荐某分路（对抗路/中路/发育路/打野/游走），默认全部分路 |
| `--mode` | 胜率分段：`dianfeng`=巅峰千强，`dazhong`=大众分段（默认）|
| `--force` | 强制重新爬取组合优势（默认按过期自动判断）|

**规则**：已选（无论我方还是敌方）与已 ban 的英雄不会再出现在推荐里。

**未满 5v5 处理**：英雄视角按 5 个槽位归一，未选槽位按「中性 50 胜率、无协同/克制」计分（csv=50，syn=cnt=0，归克制数 0 组）；查不到胜率的真实英雄按 45 兜底。阵营得分恒 /5，因此部分阵容与满阵容可比。满 5 人后即为校准的绝对胜率。

## 数据更新

### 英雄胜率（多分段）
来源：`https://tianyuanzhiyi.com/api/herostats?date=YYYY-MM-DD&gameMode={1|3|4|6}`
- 分段：`1`=全分段，`3`=1350+，`4`=顶端排位，`6`=巅峰千强（近5日聚合）。
- 爬虫抓取全部 4 个分段，每英雄保存 `m1/m3/m4/m6` 胜率；某分段缺失用 45 兜底。
- 展示分段：
  - `dianfeng`（巅峰千强）：直接用 `m6`。
  - `dazhong`（大众分段）：每个英雄的 csv 胜率按它的「对手克制数 k（0..5）」在 大众↔巅峰 间插值：
    `csv = 大众聚合值 + (巅峰千强 − 大众聚合值) × k/5`；其中大众聚合值 = `(m1*0.5 + m3 + m4 + m6*0.5) / 3`。
    即：克制数 0 → 大众胜率，克制数 5 → 巅峰千强胜率，中间线性过渡。
- 每天只更新前一天数据，优先用昨天；当天接口若已就绪则用当天。
- **每天自动刷新**：若 `hero_winrate.json` 的 `fetched_at` 不是今天，则重新拉取；当天已爬过则复用。
- 保存到 `data/hero_winrate.json`（含全量英雄与全部分段）。

### 组合优势（协同/克制指数）
来源：`https://tianyuanzhiyi.com/api/hero/analysis?heroId={id}`
- **英雄名册**直接从站点 `herostats` 接口拉取全量（含新英雄），保存为 `data/hero_registry.json`；站点失败才回退本地缓存 / 旧 1.json。
- 抓取每个英雄的 `goodSynergies`/`badSynergies`（协同）和 `counters`/`counteredBy`（克制），**并保留每条关系的 `totalMatches`（频次）**。
- 汇总为一份 `data/combo_advantage.json`（与胜率英雄数一致，当前 132）；每条关系形如 `{"idx": 指数, "m": totalMatches}`。
- **过期规则**：该文件距今 >= 5 天则重新爬取；否则直接复用。

## 模型（英雄视角 18 权重）

阵营得分拆到英雄视角：每个英雄按「对手中克制它的英雄数」落在 6 个克制组之一，
用该组的权重 `(csv/syn/cnt)` 乘它的三项评分，阵营得分 = 5 英雄评分之和 / 5，双方相减得 logit。

```
每个英雄评分（按对手克制数 k=0..5 选权重组）：
  hero_score = w_csv[k]·csv_i + w_syn[k]·syn_i + w_cnt[k]·cnt_i
    csv_i = 该英雄站点 csv 胜率（百分数）
    syn_i = (对队友有效协同指数之和) / 有效协同条数     # 0 条则 0
    cnt_i = (对对手有效克制指数之和) / 有效克制条数     # 0 条则 0
    有效关系 = combo 中 totalMatches >= 50（低频关系视为不存在）

score = (Σ 我方 hero_score)/5 − (Σ 敌方 hero_score)/5
win_rate = 1 / (1 + e^{−score})
```

18 个权重（`model.W_CNT`，按对手克制数 0..5）：

| 克制数 | csv | syn | cnt |
|--------|-------|-------|-------|
| 0 | +0.0700 | +0.0912 | 0 |
| 1 | +0.0308 | +0.0527 | +0.0350 |
| 2 | -0.0106 | +0.0631 | +0.1059 |
| 3 | -0.0504 | +0.1034 | +0.1537 |
| 4 | -0.0915 | +0.0592 | +0.2217 |
| 5 | -0.1326 | +0.0841 | +0.2373 |

- 无独热、无截距、无需归一化
- 需要 combo 数据含 `totalMatches`（`model.MIN_M=50` 过滤）
